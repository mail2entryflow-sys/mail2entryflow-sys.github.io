EntryFlow

EntryFlow is a data-entry helper for field investigators of the agricultural survey in Kerala. The investigator types the cluster figures into an Excel file or into their own Google Sheet, and EntryFlow enters those figures into the AIDEA survey app on the investigator's phone, so the same figures do not have to be typed twice.

What EntryFlow consists of

EntryFlow Android app – reads the investigator's cluster file and fills the AIDEA app on the same phone.

EntryFlow desktop app (Windows) – does the same from a PC, with the phone connected by USB.

EntryFlow Chrome extensions – help with the e-BTR survey number details and can copy the cluster formation to the investigator's own Google Sheet.

Google sign-in

Signing in with Google is optional. It is used only to create and read the investigator's own “EntryFlow <year>” Google Sheet. EntryFlow can see only the files it created itself, never the rest of the investigator's Google Drive. See the privacy policy.

Who can use it

EntryFlow is given directly to approved investigators in Kerala. It is not sold and has no advertising.
